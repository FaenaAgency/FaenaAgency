# fæna

Website for **fæna**, an independent brand, marketing & communications firm.

A static site: open `index.html` in a browser, or serve the folder with any static server.

- `index.html`, `styles.css`, `main.js`: the page, its styles and its motion (GSAP, ScrollTrigger and Lenis load from public CDNs)
- `assets/brand/`: the official marks from the fæna branding kit
- `assets/plates/`: public-domain natural-history plates, cut from their paper
- `assets/img/`: photographs; sources and credits are in `assets/img/CREDITS.md`
